    NAG:AfflictionCurrentSnapshot(actionId, targetUnit)

    Returns the current snapshot delta for Affliction DoTs or Soul Swap Exhale. Positive values indicate a stronger snapshot relative to baseline.

    Parameter Type Required Description
    actionId table\|number required ActionID describing the spell (supports raw spellId numbers)
    targetUnit string optional Optional unit token (defaults to "target")

    Returns: number — Snapshot delta (e.g., 0.15 for +15%), or -1 when unavailable

    Flavors: mists ONLY — not available in cata, sod, tbc, titan, vanilla, wrath

    NAG:BrewmasterMonkCurrentStaggerPercent()

    Returns the current stagger percentage for a Brewmaster Monk. Calculates the percentage of maximum health currently being staggered by checking Light, Moderate and Heavy stagger debuffs.

    In a rotation string:

    Returns: number — The current stagger amount as a percentage of max health (0-100)

    NAG:MageCurrentCombustionDotEstimate()

    Returns the estimated DoT damage for a Mage's Combustion. Uses actual tracked Ignite values to calculate Combustion damage, accounting for Glyph of Combustion, haste scaling, and crit chance. Only considers Ignite as the source DoT.

    Returns: number — The estimated total damage from Combustion based on current Ignite state.
